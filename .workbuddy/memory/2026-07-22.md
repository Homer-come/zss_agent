## 修复滚动行为
用户反馈：上下滑动时应只滚聊天记录，左右两栏不动。
- `html/body` 加 `height: 100%; overflow: hidden` 锁定页面级滚动
- `.app-shell` 从 `min-height: 100vh` 改为 `height: 100vh; overflow: hidden`
- `.app-sidebar` 加 `height: 100%; min-height: 0; overflow: hidden`，会话列表 `.session-stack` 改 `flex: 1 1 auto; overflow-y: auto`（去掉 max-height 240px）
- `.workspace` 加 `height: 100%; min-height: 0; overflow: hidden`
- `.chat-card` 从 `min-height: calc(100vh - 130px)` 改为 `height: 100%; min-height: 0`
- `.message-scroll`（el-scrollbar）加 `height: 100%`，确保聊天记录内部滚动
- `.companion-panel` 从 `max-height: calc(100vh - 40px)` 改为 `height: 100%; min-height: 0`
